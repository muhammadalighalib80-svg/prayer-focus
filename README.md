## 🛡️ Summary of Privacy Guarantees
- **100% Offline:** The app does not declare or use `android.permission.INTERNET`. Zero network requests or cloud telemetry.
- **Strictly Limited Accessibility Service:** Used solely to read foreground application package names during active prayer sessions. Configured with `canRetrieveWindowContent="false"`. Never reads screen text, keystrokes, messages, passwords, or personal data.
- **Zero Location Tracking:** No GPS or network location permissions. Prayer times are calculated offline using astronomical algorithms and user-selected city coordinates.
- **Zero Third Parties:** No advertising SDKs, no analytics, no crash reporting, and no data sharing.
- **Local-Only Storage:** User preferences and blocked apps are stored strictly in private, sandboxed Jetpack DataStore on the local device.
